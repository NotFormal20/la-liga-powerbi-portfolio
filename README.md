# La Liga Power BI Dashboard

Проект-портфолио аналитика данных: интерактивный дашборд по Ла Лиге в Power BI. Демонстрирует навыки ETL, DAX, визуализации и документирования.

## Цель

Построить дашборд с KPI по матчам Ла Лиги: общее число матчей и голов, структура результатов, динамика по турам, персональная статистика команд (на примере «Барселоны»).

## Что реализовано

- **Подготовка данных**: импорт CSV, очистка, приведение типов, создание справочников.
- **DAX-метрики**:
  - `Total Matches`, `Total Goals`, `Avg Goals per Match` — базовые KPI.
  - `Home Wins`, `Away Wins`, `Draws` — структура результатов.
  - `Barcelona Total Goals` — персональная метрика (сумма голов дома и в гостях).
  - `Cumulative Goals by Matchday` — накопительный итог по турам.
- **Визуализации**: карточки KPI, столбчатые диаграммы по турам, круговая диаграмма структуры результатов.
- **Интерактив**: срезы по `HomeTeam`, `Matchday`, кросс-фильтрация всех метрик.

## Стек

- Power BI Desktop  
- DAX  
- Power Query  
- Git / GitHub  

## Как запустить

1. Скачать `LaLiga_Dashboard.pbix`.  
2. Открыть в Power BI Desktop.  
3. При необходимости обновить источник данных (CSV).
